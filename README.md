# appiumJavaIndustryLevelFremework

An industry-level Appium automation framework built with Java, TestNG, and Maven for
native, hybrid, and mobile web apps on Android and iOS. Features Page Object Model,
thread-safe parallel execution, Allure reporting, Log4j2 logging, and Jenkins CI/CD.

---

## 🚀 Tech Stack

| Tool | Purpose |
|---|---|
| Java 17 | Programming language |
| Appium 2/3 | Mobile automation |
| TestNG | Test runner |
| Maven | Build & dependency management |
| Allure | Test reporting |
| Log4j2 | Logging |
| Apache POI | Excel test data |
| Jackson | JSON handling |
| Jenkins | CI/CD |

---

## 📱 Platform Support

- **Android** – UiAutomator2 driver, emulators
- **iOS** – XCUITest driver, simulators
- **Cloud** – BrowserStack (configurable)
